# Brand / platform assets

Included:
- `favicon.ico` — multi-resolution browser favicon.
- `assets/brand/favicon-16x16.png`
- `assets/brand/favicon-32x32.png`
- `apple-touch-icon-v2.png` — 180×180 iOS bookmark/home-screen icon.
- `icon-192-v2.png` and `icon-512-v2.png` — app icons.
- `og-image-v2.png` — 1200×630 Open Graph / social share card.
- `site.webmanifest`

The social card intentionally contains only the site identity: `KILE JONES` and `KILEJONES.COM`.
No invented tagline or additional claim is included.

The icon system uses the compact `KJ` mark on a dark background.

Small browser favicon sizes intentionally use a single `K` mark for legibility; larger home-screen/app icons use `KJ`.
