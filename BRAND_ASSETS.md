# Brand / platform assets

Included:
- `favicon.ico` — multi-resolution browser favicon.
- `assets/brand/favicon-16x16.png`
- `assets/brand/favicon-32x32.png`
- `apple-touch-icon.png` — 180×180 iOS bookmark/home-screen icon.
- `assets/brand/icon-192.png`
- `assets/brand/icon-512.png`
- `assets/brand/og-image.png` — 1200×630 Open Graph / social share card.
- `site.webmanifest`

The social card intentionally contains only the site identity: `KILE B. JONES` and `KILEBARDENJONES.COM`.
No invented tagline or additional claim is included.

The icon system uses the compact `KBJ` mark with the same dark metallic/oil visual language as the homepage reveal.

Small browser favicon sizes intentionally use a single `K` mark for legibility; larger home-screen/app icons use `KBJ`.
