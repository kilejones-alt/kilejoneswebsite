SELF-HOSTED FONTS
This package contains a GitHub Action at .github/workflows/vendor-fonts.yml.
On the first push to main (if the WOFF2 files are not already present), it fetches the open-source Inter Tight and IBM Plex Mono source files from a pinned google/fonts commit, converts them to WOFF2, saves them under assets/fonts/, and commits those generated webfonts back to the repository.
That commit makes the actual WOFF2 files permanent repository assets. Later site updates do not require you to upload the fonts again; if they are ever missing, the workflow recreates them automatically.
After that, the live site makes no runtime requests to Google Fonts.
Leave the .github folder in the upload.
The workflow also requests a GitHub Pages rebuild after the font commit, because GitHub Pages does not automatically rebuild from commits made with GITHUB_TOKEN.
